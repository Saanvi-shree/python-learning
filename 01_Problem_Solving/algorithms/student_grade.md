# Algorithm: Find the Grade of a Student
## Problem
Write an algorithm to input the marks of five subjects and find the grade of a student based on the percentage.
## Input
Marks obtained in five subjects.
## Output
The percentage and grade of the student.
# Algorithm: Calculate Percentage and Grade
1. Input S1, S2, S3, S4, S5.
2. Compute Total = S1 + S2 + S3 + S4 + S5.
3. Compute Per = Total / 5.
4. Print Total, Per.
5. If Per < 60,
6. then print Grade E.
7. Else if Per < 70,
8. then print Grade D.
9. Else if Per < 80,
10. then print Grade C.
11. Else if Per < 90,
12. then print Grade B.
13. Else if Per ≤ 100,
14. then print Grade A.
15. Else,
16. print Invalid Marks.
17. [End if]
18. Stop.
