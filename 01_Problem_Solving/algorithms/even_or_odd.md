# Algorithm: Check Whether a Number is Even or Odd
## Problem
Write an algorithm to check whether a given number is even or odd using an if-else statement.
## Input
A number N.
## Output
Whether N is even or odd.
## Algorithm
1. Start
2. Input N
3. If N % 2= 0, then print "Even"
4. Else, print "Odd"
5. [End if]
6. Stop
