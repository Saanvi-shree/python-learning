# Algorithm: Find the Reverse of a Number
## Problem
Write an algorithm to find the reverse of a given number.
## Input
A positive integer N.
## Output
The reverse of N.
# Algorithm: Reverse a Number
1. Start.
2. Input N.
3. Set X = N.
4. Set Sum = 0.
5. While X != 0,
- repeat steps 5 to 8.
6. Digit = X % 10.
7. Sum = Sum * 10 + Digit.
8. X = X // 10.
- End of while loop.
9. Print Sum.
10. Stop.
